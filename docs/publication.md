# Publication scope and historical evidence

This repository is a publication copy of the verified Completion Step 06 sources. Application code and dependency versions retain their captured Step 06 bytes. Subsequent CI portability repairs run the secret scanner sequentially under its unchanged socket guard, supply a lock-verified wheel for offline clean installation, and verify the actual native RapidFuzz extension across supported CPU backends. Tests remain enabled; the Python fallback is rejected. Later Completion Step 07 work is outside this snapshot. The prototype suggests possible record matches for human research review; it does not establish identity, wrongdoing or clearance and is not a live screening service.

The published data inputs are authored fictional fixtures and four saved fictional regression artifacts required by the existing tests. They are exposed examples for software regression checks, not new held-out evaluation evidence. Original public-source datasets and detailed public evaluation outputs, model weights, local environments, review stores, reviewer notes, preservation archives and private verification receipts are excluded. Finder metadata is excluded too.

The publication copy of [the Phase 2 report](progress/phase-02.md) explicitly omits its real provider-record excerpt and corresponding query command. The unchanged original remains preserved locally. This omission changes no application or test behavior. The [data card](data-card.md) and [model card](model-card.md) retain historical source/model descriptors and their limits; those descriptors do not supply new redistribution permissions.

Historical reports retain their original status statements and command transcripts. Statements such as “no hosted run” describe the state when the report was completed; later hosted evidence belongs to the matching GitHub Actions run and commit. The local fixture-completeness rehearsal of this Step 06 code passed 1,644 non-integration tests and 13 subtests, with three opt-in model tests deselected. It used the existing macOS Python environments with imports directed to the captured source copy; it was not a clean Linux installation or a hosted run.

## Historical links that are unavailable in this repository

References into `data/eval-comparisons/` and `data/review-archives/` identify local evidence that is deliberately unpublished. They are unavailable in this repository. In particular, the linked receipts in the [access/resource ledger](access-and-resource-ledger.md), [Step 00 report](progress/completion-00.md), and [Step 06 report](progress/completion-06.md) remain local; no replacement evidence has been invented.

The Step 00 report also contains absolute file links beginning with the original local project path. These are historical local source citations, not portable web links. Their source counterparts are available through the repository tree. Original command paths and the local account label `odin` remain historical host metadata; the simulated demo actor label is not proof of a human reviewer’s identity.

Current navigation from the README uses repository-relative documentation links. These historical exceptions are documented here so a missing private receipt is not mistaken for a published artifact or a new validation result.
